# 危重急症抢救流程 · 刷题助手

依据《危重急症抢救流程解析及规范》（何庆 著，2007）整理的单页 Web 刷题软件，覆盖全书 26 章抢救流程，共 500 题（常规单选 370 题 + 病例分析单选 130 题）。

## 使用方式

**直接双击 `index.html` 即可在浏览器中打开使用**（无需服务器、无需联网）。

> 建议使用 Chrome / Edge 最新版。数据保存在浏览器本地（localStorage），同一浏览器内自动累计练习统计与错题本。

## 功能

| 功能 | 说明 |
|---|---|
| 📖 练习模式 | 逐题作答，选完即判分并显示解析与知识点溯源；可按章节/题型筛选、随机打乱 |
| ⏱️ 模拟考试 | 10/20/40 题连答不提示答案，交卷后统一判分、环形得分、逐题复盘 |
| 📕 错题重做 | 答错的题自动进入错题本（localStorage），可单独重做；答对自动移出；可一键清空 |
| 📊 首页统计 | 已练习题数、错题数实时显示；26 章目录可点击直达该章练习 |
| ⌨️ 键盘快捷键 | 数字键 1-4 选择选项，回车确认 / 下一题 |

## 题目结构（题库.json）

```json
{
  "id": 1,
  "type": "single_choice | case_analysis",
  "question": "题目内容",
  "case": "（病例分析题可选字段）临床情景",
  "options": ["A. 选项1", "B. 选项2", "C. 选项3", "D. 选项4"],
  "answer": "A",
  "explanation": "解析：正确项依据 + 各错误项为何不对",
  "knowledge_point": "第X章 XXX流程 - XXX小节"
}
```

- `type=single_choice`：常规单选题（定义、流程步骤、药物剂量、适应证/禁忌证等）
- `type=case_analysis`：病例分析单选题（临床情景 + 首选处理/最可能诊断），`case` 字段存放情景描述
- `knowledge_point`：知识点在书中的章节/小节定位
- `explanation`：基于原书内容的详细解析

## 手动添加题目

打开 `add_question.html`（或在刷题首页点右上角「✏️ 题库管理」）：

1. 选择题型、填写章节/小节（可从下拉选已有章节）、题干、四个选项（**不用**加 "A./B." 前缀）、正确答案、解析；病例分析题另填临床情景
2. 点「添加题目」；列表里可随时删除题目
3. 点「⬇ 下载 questions.js」，把下载的文件覆盖到 `data\questions.js`，刷新 `index.html` 即生效

> 批量改题也可直接编辑 `题库\题库.json`（每道题一个 JSON 对象，字段结构见上），改完把整个数组按同样格式写回 `data\questions.js`（`window.QUESTIONS = [...]`）。

### 来源和版本

题目按提供的《危重急症抢救流程解析及规范》（何庆，2007）扫描PDF知识点编写。新增题解析中的页码可回查原书；病例经过教学化改编。扫描文字经OCR提取，重点条目结合书页图像抽查。未按现行指南重新审校全部医学内容，也未由临床专家逐题审核；涉及药物剂量、复苏和溶栓等内容应另核现行规范。

### 数据文件维护

index.html实际读取data/questions.js。data/questions.json是本次更新时的同内容快照，网页题库管理仍只导出questions.js；之后通过网页改题，不会自动修改磁盘JSON文件。若批量编辑JSON，请同时将数组写回questions.js的window.QUESTIONS赋值。
